# Barrel Race

Gra wyścigowa 3D stworzona w **Unity** z użyciem języka **C#**.

## Opis rozgrywki

Prowadzisz samochód prostą drogą usianą beczkami. 
Twoim celem jest dotrzeć do mety bez uderzenia w żadną przeszkodę. 
Uderzenie w beczkę = przegrana. Dotarcie do mety = wygrana.

## Mechaniki

- Sterowanie pojazdem w środowisku 3D (Rigidbody physics)
- Detekcja kolizji: pojazd vs beczka (przegrana), pojazd vs meta (wygrana)
- Kamera śledząca pojazd
- Ekrany wygranej i przegranej z możliwością restartu

## Technologie

- **Unity** (3D)
- **C#**
- **Git / GitHub**

## Uruchomienie

1. Sklonuj repo: `git clone https://github.com/jMazur02/BarrelRace`
